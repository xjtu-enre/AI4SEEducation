# ArchSentinel Tech 展示站

这是 ArchSentinel 的产品介绍与技术文档站，基于 Docusaurus 构建。首页提供系统入口，文档区介绍 ArchMapper、ArchInspector、ArchCompass、ArchVitals、ArchBrain 和 ArchNurse 等模块。

## 环境要求

- Node.js 18 或更高版本
- npm

## 本地运行

```powershell
npm install
npm run start
```

默认访问地址为 <http://localhost:3000/>。

## 生产构建

```powershell
npm run build
```

静态站点生成在 `build` 目录，可使用 `npm run serve` 进行本地预览。
