# ArchMapper 
## 架构测绘仪

ArchMapper 从代码仓库中提取结构性实体和符号级实体之间的关系，把分散在文件中的代码组织成可以观察和分析的软件地图。它是 ArchSentinel 的数据基础，后续的质量检查、反模式识别和版本比较都建立在这张依赖图谱之上。

## 分析内容

- 识别包、文件、类、接口、方法和变量等代码实体。
- 提取调用、继承、实现、参数、返回值、字段访问等依赖关系。
- 按项目、模块和实体层级展示结构，支持从整体关系逐步下钻到局部代码。
- 统计实体类型、关系类型、文件数量、项目规模和代码行数。
- 对原始版本与最终版本进行并列展示，为版本演化分析提供输入。

## 技术思路

ArchMapper 使用静态分析建立抽象语法与符号信息，并结合指向分析解析可能的依赖绑定。对于仅靠文本搜索难以确认的调用关系，系统根据作用域、类型和可达定义进行判断，形成细粒度依赖摘要。既有项目材料显示，该能力面向 Java、C/C++、Python 等多种编程语言进行了研究和验证。

## 页面展示

进入 ArchMapper 后，页面左右分别对应原始版本和最终版本。每一侧都可以查看：

1. 项目名称、文件数量、项目大小和代码行数。
2. 不同实体类型与关系类型的数量分布。
3. 全局依赖关系图及局部关系明细。
4. 耦合、内聚、继承、封装和多态等项目指标。

## 教学价值

学生通常以文件或函数为单位编写代码，很难直接感知一次修改对其他模块造成的影响。ArchMapper 把调用链和模块边界可视化，帮助学生理解高耦合、职责扩散和不合理依赖。教师也可以依据依赖图判断模块划分是否符合课程设计要求，而不必逐个文件人工梳理。
